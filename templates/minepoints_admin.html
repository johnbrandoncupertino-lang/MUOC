Production earning safety

All rates and activity types start disabled. Do not enable a rate until the approved numerical value and the event calculation have been reviewed. A rate means points awarded per 100 Emeralds of eligible amount; awards round down to whole points. A zero-point calculation creates no award. Fee-paying services require explicit approval.

This page does not retroactively award points. Rate changes create a new rule version and apply to future eligible events only.

Eligible activity types

Only completed external activity is eligible. Own-account transfers, failed activity, credit draws/repayments, loan activity, and reversals are excluded. Enabling an event type does not itself enable any tier's earning rate.
